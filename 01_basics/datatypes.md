# Object types / Data types

- Number: 1234, 3.14, 3+4j, fraction(), decimal(), 0b111
- String: 'spam', "bob's", b'a\x01c', u'sp\xc4m'
- List: [1, [2, 'three], 4.5], list(range(10))
- Tuple: (1, 'spam', 4, 'U'), tuple('s p a m'), namedtuple('Point', ['x', 'y'])
- Dictionary: {'food': 'spam', 'taste': 'yum'}, dict([('s', 1), ('p', 2), ('a', 3), ('m', 4)])


- Set: {'s', 'p', 'a', 'm'}, set('spam'), frozenset('spam') 
- Boolean: True, False
- File: open('data.txt'), open('data.txt', 'w')
- None: None
- Functions, classes, modules

- Advance: Decorators, generators, iterators, metaProgramming
